# Curriculum Documentation

Curriculum _content_ (concepts, lessons, assessments, knowledge graph data) is not documentation — it lives as structured data under [/curriculum](../../curriculum) and is validated against the schemas in [packages/curriculum-schema](../../packages/curriculum-schema).

This folder is for documentation _about_ the curriculum: coverage notes against the NSW Years 7–10 Science syllabus, content authoring guidelines, and mapping decisions (e.g. how syllabus outcomes map to concept nodes). Populated as the Product Owner supplies curriculum content.
