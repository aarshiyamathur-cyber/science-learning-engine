## Live demo

**Public URL:** https://divx-ips-resistance-acoustic.trycloudflare.com

This is a Cloudflare anonymous quick tunnel to the dev machine's own `next start` production server — no cloud hosting, no account, data stays on-device (`node:sqlite`, per ADR 0006). It only works while: (1) this machine stays on and connected to the internet (currently via mobile hotspot), and (2) the `cloudflared` process and the Next.js server keep running. The URL is ephemeral — it changes every time the tunnel is restarted.
