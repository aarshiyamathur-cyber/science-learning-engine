# AI Handoff Protocol

This file is the single handoff point between Product, Claude Code and OpenClaw.

## Claude Code Checklist
1. Read CURRENT_SPRINT.md
2. Break work into engineering tasks.
3. Delegate implementation to OpenClaw workers.
4. Review all outputs.
5. Merge accepted work.
6. Update DASHBOARD.md.
7. Record architecture/product decisions in DECISIONS.md.
8. Stop and wait for Product review.

## OpenClaw Checklist
- Execute assigned tasks only.
- Commit code.
- Write tests.
- Report failures back to Claude.
- Do not change sprint scope.
